# 📰 Fake News Detection App

## 📌 Overview
This project detects whether news is real or fake using Machine Learning.

## ⚙️ Tech Stack
- Python
- Scikit-learn
- TF-IDF
- Streamlit

## 🚀 Features
- Input news text
- Predict Real or Fake
- Confidence score

## ▶️ How to Run
1. Install dependencies
2. Run: streamlit run app.py

## ⚠️ Note
Dataset and model files are not included due to size limits.
